# Cognitive Load Companion

A GitHub Pages-ready HTML/CSS/JavaScript presentation inspired by the supplied Kreyato preview.

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub to publish the site.

Use the arrow buttons, keyboard arrows, spacebar, or swipe on mobile to move through the 9 slides.
